## 화면에서 확인할 것

- `위젯 상태`를 바꾸며 2×2·2×1 두 크기의 문구·칩·CTA 차이를 본다. 업데이트 중은 CTA가 없고 헤더에 `업데이트 중`이 붙는다.
- `로고 모션` 5종을 비교한다. 원안(정지) · 슬롯 교체 · 세트 교체 · 흐름 · 스캔.
- `로고 톤`으로 정책의 '흐리게'와 디자인의 '선명'을 나란히 본다.
- `로고 풀`을 `전체`로 바꾸면 교체 풀 39개까지 순환한다.
- 시스템 동작 줄이기가 켜져 있으면 모든 모션이 정지 상태로 고정된다.

## 모션 5종

| 모션 | 동작 | 맞는 자리 |
| --- | --- | --- |
| 원안 · 정지 | 로고 4개 고정. 밑줄 문구만 롤링(피그마 주석 `원하는 연봉의 → 직무와 일치하는 → 원하는 지역의`) | 동작 줄이기 사용자, 기준 상태 |
| 슬롯 교체 | 2.6초마다 한 자리씩 축소·페이드로 다른 기업으로 바뀐다. 교체 순서 1→3→0→2 | 메모리 없음 2×2 |
| 세트 교체 | 밑줄 문구가 바뀔 때 로고 4개가 90ms 간격으로 함께 바뀐다 | 문구와 로고를 한 묶음으로 보여 주고 싶을 때 |
| 흐름 | 로고가 옆으로 흐른다. 양 끝 페이드 마스크, 마우스 올리면 정지 | 메모리 없음 2×1 |
| 스캔 | 하이라이트가 좌→우로 훑고 각 로고가 순서대로 살짝 떠오른다. 한 사이클 끝에 한 자리 교체 | 메모리 업데이트 중 |

권장: 메모리 없음은 2×2 슬롯 교체·2×1 흐름, 업데이트 중은 스캔.

### 추리기 기준

1. 취준생 인지도. 소비자 브랜드·대기업·공기업을 우선한다.
2. 로켓지원 공고 수. 위젯의 약속이 실제로 성립하는 기업이어야 한다.
3. 72px 원형 안 가독성. 워드마크가 지나치게 작거나 가는 로고는 제외한다.
4. 산업 다양성. IT·금융·제조·항공·식품·유통·에너지·공기업이 한 세트 안에 섞이게 한다.

### 수집 방법 (2026-09-23 스냅샷)

- 목록: `https://api.jobda.im/v2/position?recruitNoticeVersions=V2&orderType=LATEST&size=100&page=N`. `recruitNoticeVersions=V2`가 화면의 `로켓지원 공고` 필터다. 응답의 `pages.totalElements`는 `(page+1)×size`로 잘려 나오므로 빈 페이지가 올 때까지 순회한다.
- 결과: 공고 2,779건, 기업 179개, 로고 있는 기업 150개. 로고가 없는 기업 중 공고가 많은 곳은 (주)비지에프 46건, 가톨릭대학교 인천성모병원 37건.
- 로고: `logoImageUrl`(`static.jobda.im/public/{uuid}`)은 Accept 헤더와 무관하게 webp로 응답한다. `sips`로 PNG 변환 후 `sharp`로 정규화했다.

## 검토 포인트

- 정책 v0.24는 로고를 '흐리게', 디자인은 선명하게 그렸다. 어느 쪽으로 맞출지 결정이 필요하다.
- 실제 로고는 흰 배경 워드마크가 대부분이라 피그마의 단색 원형 자리표시자와 인상이 다르다. 테두리 링과 트림으로 보정했지만 디자인 확인이 필요하다.
- 기업 로고를 위젯에 노출하는 데 고객사 동의가 필요한지 B2B 쪽 확인이 필요하다.
